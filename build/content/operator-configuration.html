Operator configuration

Every operator flag, its Helm value, and what happens when an optional integration is absent. Flags configure the operator once; per-app behavior lives in the WorkerApp resource.

Trust and scope

These flags decide which WorkerApps the operator accepts. A WorkerApp outside them reports SpecValid: False and nothing is created for it.

FlagHelm valueDefaultPurpose
--allowed-image-prefixesoperator.allowedImagePrefixesghcr.io/denoland/celld:Comma-separated prefixes a celld.image must start with.
--allowed-iam-rolesoperator.allowedIAMRolesemptyExact role ARNs allowed in credentialsFrom.iamRole.
--allowed-azure-client-idsoperator.allowedAzureClientIDsemptyExact Azure workload identity client IDs allowed in credentialsFrom.azureClientID.
--allowed-bucket-endpointsoperator.allowedBucketEndpointsemptyExact HTTPS endpoints allowed in bucket.endpoint; empty permits AWS S3 only.
--watch-namespaceoperator.watchNamespaceempty (cluster-wide)Restrict reconciliation, the cache, and the chart's workload Role to one namespace.

The operator exits at startup on an unknown ingress mode or a non-positive poll interval.

The manager runs non-root with a restricted security context and exposes its own health probes on :8081 (not celld's). Keep the control-plane: controller-manager and app.kubernetes.io/name: celld-operator labels on manager pods: fleet NetworkPolicies select them.

Graceful degradation

The operator requires none of its optional integrations to start reconciling. Absence is reported per WorkerApp, not failed on:

MissingEffectCondition
Gateway API CRDs (httproute mode)Hostnames are not routed; the fleet still serves in-clusterIngressReady: False
Istio CRDsNetworkPolicy alone guards :8081; no mesh mTLSMeshPolicyReady: False
KEDA (autoscaled apps only)spec.autoscaling has no effectAutoscalingReady: False
PrometheusKEDA scalers error; no replica changes are made on missing datanone: alert on KEDA

Store qualification tooling

The repository ships hack/cas-hammer, the concurrency probe for qualifying object stores: 

$ go run ./hack/cas-hammer --bucket <bucket> --endpoint <url> --writers 8 --rounds 32
